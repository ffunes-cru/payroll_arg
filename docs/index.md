# Nómina Argentina para Odoo 19

Liquidación de sueldos argentina sobre el módulo `payroll` de OCA: jornalizados UOM (quincenas) y
mensualizados, vacaciones, SAC, liquidación final, Ganancias 4ta categoría, recibo PDF, Libro de Sueldos
Digital, F.931 y acreditaciones bancarias. Software libre bajo
[AGPL-3](https://github.com/ffunes-cru/payroll_arg/blob/main/LICENSE).
